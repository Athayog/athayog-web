# Athayog Web

Yoga and wellness platform built with Next.js.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- **Framework:** Next.js 16 (App Router)
- **Fonts:** Cormorant Garamond, Cinzel, Inter (via `next/font`)
- **Styling:** CSS custom properties
